PBIX Viewer

Check the data inside a Power BI file

Open a .pbix to see every table, row and total it holds, read its measures and report fields, and copy anything into Excel to compare.

Your file stays on this computer. This page reads it in your browser and never uploads it.

Tables and rows

Every table in the model with search, filters, sorting and a totals row that follows your filters.

Column checks

Non-blank, blank and distinct counts, minimum, maximum and sum for each column.

Measures

The DAX of each measure, with the grand total worked out for simple ones.

Visual check

The rows each report visual should show, rebuilt with its filters, to compare with Power BI.

Copy to Excel

Copy any table or SQL result and paste it straight into a sheet, or download a CSV.
